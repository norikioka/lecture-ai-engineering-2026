## 宿題：基礎

### 実施条件
- 実施日：2026年10月24日（JST）
- モデル：`gemini-3.5-flash-lite`、`gemini-3.8-flash`
- 質問：`LoRAとは何ですか？` と `AIE2026の講座の宿題にある「3レベル」とは何ですか？`
- 各モデル・各質問で3回ずつ回答を取得（成功12回）。別に503による失敗が1回あり、生成APIの試行は合計13回。
- 各回は会話履歴のない独立した呼び出し。システム指示・参考資料・検索ツールを追加せず、temperatureなどの生成設定は指定していない。モデルごとの既定設定が同一であるとは限らない。
- 講座の `app.ask` を変更せず、`AIE_MODEL` で切り替えて実行。Python 3.12.13、講座の `uv.lock` で依存を固定。

- 実行元コミット：`662cddd52724b330f3f4cd15123d1e55cb474874`

環境変数 `GEMINI_API_KEY` を設定した状態で、以下をそれぞれ3回実行する。キーをコードやログに書かない。

```bash
AIE_MODEL=gemini-3.5-flash-lite uv run --frozen --python 3.12 python -m app.ask "LoRAとは何ですか？"
AIE_MODEL=gemini-3.8-flash uv run --frozen --python 3.12 python -m app.ask "LoRAとは何ですか？"
AIE_MODEL=gemini-3.5-flash-lite uv run --frozen --python 3.12 python -m app.ask "AIE2026の講座の宿題にある「3レベル」とは何ですか？"

```

上記は質問を再実行するコマンドであり、JSON保存・待機・タイムアウトを含む一括収集処理ではない。記録保存と待機は実行時の補助処理で行った。モデルの更新や生成の揺れにより、同一の文章が再現するとは限らない。

### 比較結果

#### 一般用語：LoRA

6回答すべてで、Low-Rank Adaptationという名称と、元モデルの全体を更新せず、一部だけを学習する大枠が説明されていた。Liteの2回目は「大部分を固定」「ごく一部のパラメータだけ学習」という記述に留まり、追加行列を学習するという区別は明確ではなかった。ただし、用語集にある「更新分を2つの小さな行列の積で表す」という説明の詳しさは一定ではなかった。

| モデル | 1回目 | 2回目 | 3回目 |
|---|---|---|---|
| gemini-3.5-flash-lite | 辞書と付箋の比喩で、仕組み・メリット・用途を説明 | メモリ・学習時間・ファイルサイズなどメリットを中心に説明 | 元の重みを固定し低ランク行列の差分を追加する説明。補足ノートの比喩 |
| gemini-3.8-flash | 辞書と付箋の比喩、低ランク行列、GPUの具体例を提示 | 2つの小さな行列の説明と無線通信LoRaとの区別を追加 | 辞書とメモ帳の比喩。差分を別部品として学習する説明 |

Liteの3回答に「数分〜数時間」など学習時間の表現があったが、モデル規模・データ量・ハードウェアの条件は示されていない。またLiteの2回目とFlashの3回目には「学習するデータ量」を減らす趣旨の表現があった。用語集が述べるのは主に学習するパラメータ数の削減であり、学習データの件数が自動的に減るという意味には解釈しない。

この6回答からは、説明の骨格は似ていても、具体例・比喩・技術的な詳しさが揺れることが観察できた。「説明が長い」「読みやすい」だけで正確性を判断せず、条件の省略や用語の区別を確認する必要がある。

#### 講座固有の質問：宿題の3レベル

用語集の `homework-levels` と課題文を基準に、「基礎・実装・発展」の3名称と「いずれか1つに取り組めば完了」という条件を確認した。

| モデル | 1回目 | 2回目 | 3回目 |
|---|---|---|---|
| gemini-3.5-flash-lite | 教材を直接確認できないと明示。AI活用・開発・プロンプトの3パターンを提示 | 教材を確認できないと明示。「基礎・応用・発展」などの一般的分類を提示 | 一般的な難易度として「基礎・応用・発展」を説明し、資料の確認を促す |
| gemini-3.8-flash | 難易度とAI活用の2パターンを提示。「基礎は全員必須」という候補を記述 | 達成水準・プロンプト・理解度の3パターンを提示。「レベル1までが提出必須」と一般化 | 基礎・応用・発展の達成基準を説明。「単位や修了要件だけであればLevel 2までで十分なケースが多い」と記述 |

成功した6回答のいずれも、講座の正式な3名称とその回の宿題の完了条件の組合せを正しく特定していなかった。両モデルとも資料の確認を促しているものの、その前に課題例や提出基準を詳しく補っている。したがって、単純に「知らないことを断言した」と一括りにせず、不確かさを示す表現と、根拠を確認できない具体的な補完を分けて読んだ。

Liteの1・2回目は教材を確認できないと明示したが、3回目は一般論から説明を始めた。Flashでも、挙げるパターンの数や提出要件の説明が変わった。今回の観察では、一般用語の説明ができることと、この講座の提出ルールを知っていることは別だった。

#### 失敗した試行

Flashの講座固有質問の初回試行は、終了コード1で「モデルが混み合っています（503）」となった。[失敗ログ](results/homework_gemini-3.8-flash_1_failed-attempt-1.json)を残し、成功回数には含めていない。間隔を空けた再試行は成功した。429は観測しておらず、この503を無料枠のレート制限と断定しない。

### 気づき

比較で難しかったのは、文章の流暢さと根拠の確かさを分けて評価することだった。同じ質問を繰り返し、原文を用語集と照合したことで、説明の揺れだけでなく、条件の省略や講座固有情報の補完も確認できた。実際の利用では、提出条件などの重要な事実は一次資料で確認し、必要な資料を入力に与えた場合の違いも今後確かめたい。ただし、資料を与える実験は今回は実施していない。
